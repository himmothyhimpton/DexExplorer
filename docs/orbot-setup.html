Orbot & Tor Setup (Android)

Follow these steps to route supported app traffic through the Tor network.

1) Install Orbot

  • Get Orbot from trusted sources: Google Play or F‑Droid.
  • Launch Orbot and follow on‑screen instructions to establish a secure Tor connection.
  • Ensure Orbot shows Connected before using Tor‑dependent features.

2) Tor Browser

  • Install the official Tor Browser from Google Play.
  • With Orbot connected, open Tor Browser — it automatically routes via Tor.
  • Recommendation: Use Tor Browser exclusively for web browsing through Tor. Other browsers may leak identifying information and lack Tor’s protections.

3) Other Apps (e.g., Bitwarden, Element)

  • Open each app’s Settings.
  • Find network proxy or VPN configuration options.
  • Select the Orbot VPN profile to route traffic via Tor.
  • Verify connection status inside each app.

4) Integrating with This App

  • Features that require Tor (e.g., loading .onion links) will prompt you when a Tor route is not active.
  • Start Orbot and ensure it is connected, then select a Tor route in the app’s Diagnostics → Connect panel.
  • On some devices, Orbot exposes a local SOCKS5 proxy at 127.0.0.1:9050. The app will detect Tor availability automatically when possible.

5) Privacy & Safeguards

Important: Orbot uses a VPN profile to route traffic but is not a traditional VPN service. It provides Tor anonymity routing. Avoid mixing Tor with personal accounts on the same browser profile.

  • Use Tor Browser for privacy‑critical browsing; avoid alternative browsers with inadequate fingerprinting defenses.
  • Prevent information leaks by keeping non‑Tor traffic separate and reviewing app proxy/VPN settings regularly.
  • If an app misbehaves behind Tor, disable its background network access or remove its VPN/proxy override.

6) Troubleshooting

  • Ensure Orbot is fully connected before opening Tor‑dependent features.
  • If the app does not detect Tor, confirm the Orbot VPN profile is active or SOCKS5 proxy is reachable.
  • Check for captive portals or unstable connectivity that can interrupt Tor circuits.
